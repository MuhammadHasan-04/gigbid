# GigBid (public demo)

Multi-agent freelancer copilot. Source: see the GitHub repository. Secrets set in the Space settings:
`GROQ_API_KEY`, `APP_SECRET_KEY`, `TOKEN_ENC_KEY`, `APPROVAL_SECRET`, `REVIEWER_EMAIL`, `REVIEWER_PASSWORD`,
`MODEL_PROFILE=open`, optional `DATABASE_URL` (Neon) and `LANGFUSE_*`.
