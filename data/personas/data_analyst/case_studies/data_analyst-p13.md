# A/B test analysis for fintech growth team

**Client:** Quill Learning (fintech) · **Year:** 2020

## Problem
Quill Learning needed help with a/b test analysis for fintech growth team. Their team had tried spreadsheets and ad-hoc scripts, and the process did not scale.

## What I did
I designed and built the solution end to end using A/B testing, confidence intervals, python 3, tidyverse and window functions. I ran weekly demos and wrote handover docs.

## Result
The project improved accuracy from 74% to 84%.
