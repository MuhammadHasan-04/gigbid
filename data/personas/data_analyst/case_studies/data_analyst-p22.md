# A/B test analysis for travel growth team

**Client:** Northwind (travel) · **Year:** 2023

## Problem
Northwind needed help with a/b test analysis for travel growth team. Their team had tried spreadsheets and ad-hoc scripts, and the process did not scale.

## What I did
I designed and built the solution end to end using A/B testing, hypothesis testing, SQL, Python and ggplot2. I ran weekly demos and wrote handover docs.

## Result
The project brought latency down to 120 ms p95.
