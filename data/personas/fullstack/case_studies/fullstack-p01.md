# SaaS dashboard for a SaaS startup

**Client:** Pixelpress (SaaS) · **Year:** 2023

## Problem
Pixelpress needed help with saas dashboard for a saas startup. Their team had tried spreadsheets and ad-hoc scripts, and the process did not scale.

## What I did
I designed and built the solution end to end using component-based SPA, typed JavaScript, a JavaScript backend, card payments and tailwind classes. I ran weekly demos and wrote handover docs.

## Result
The project brought latency down to 120 ms p95.
