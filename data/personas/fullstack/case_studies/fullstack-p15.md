# GraphQL API for a non-profit product

**Client:** Greenroots NGO (non-profit) · **Year:** 2020

## Problem
Greenroots NGO needed help with graphql api for a non-profit product. Their team had tried spreadsheets and ad-hoc scripts, and the process did not scale.

## What I did
I designed and built the solution end to end using GraphQL, server-side JS, typed JavaScript, MongoDB, JS unit tests and PostgreSQL. I ran weekly demos and wrote handover docs.

## Result
The project improved accuracy from 70% to 81%.
