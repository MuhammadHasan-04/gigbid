# SaaS dashboard for a healthcare startup

**Client:** Shieldline (healthcare) · **Year:** 2021

## Problem
Shieldline needed help with saas dashboard for a healthcare startup. Their team had tried spreadsheets and ad-hoc scripts, and the process did not scale.

## What I did
I designed and built the solution end to end using React, strict TS, Node.js, utility-first CSS and OAuth. I ran weekly demos and wrote handover docs.

## Result
The project improved accuracy from 75% to 80%.
