# SaaS dashboard for a e-commerce startup

**Client:** Shieldline (e-commerce) · **Year:** 2020

## Problem
Shieldline needed help with saas dashboard for a e-commerce startup. Their team had tried spreadsheets and ad-hoc scripts, and the process did not scale.

## What I did
I designed and built the solution end to end using component-based SPA, typed JavaScript, a JavaScript backend, social login and tailwind classes. I ran weekly demos and wrote handover docs.

## Result
The project cut manual review time by 33%.
