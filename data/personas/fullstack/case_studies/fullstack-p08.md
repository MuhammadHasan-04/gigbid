# GraphQL API for a SaaS product

**Client:** Quill Learning (SaaS) · **Year:** 2026

## Problem
Quill Learning needed help with graphql api for a saas product. Their team had tried spreadsheets and ad-hoc scripts, and the process did not scale.

## What I did
I designed and built the solution end to end using GraphQL, Node.js, TypeScript, Mongo collections, JS unit tests and PostgreSQL. I ran weekly demos and wrote handover docs.

## Result
The project improved accuracy from 74% to 80%.
