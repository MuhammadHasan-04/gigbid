# SaaS dashboard for a e-commerce startup

**Client:** Kitebook (e-commerce) · **Year:** 2020

## Problem
Kitebook needed help with saas dashboard for a e-commerce startup. Their team had tried spreadsheets and ad-hoc scripts, and the process did not scale.

## What I did
I designed and built the solution end to end using React, strict TS, a JavaScript backend and single sign-on. I ran weekly demos and wrote handover docs.

## Result
The project shipped in 10 weeks.
