# REST API backend for media mobile app

**Client:** Shieldline (media) · **Year:** 2025

## Problem
Shieldline needed help with rest api backend for media mobile app. Their team had tried spreadsheets and ad-hoc scripts, and the process did not scale.

## What I did
I designed and built the solution end to end using Node.js, RESTful endpoints, PostgreSQL, AWS, decorator-based Node services and container images. I ran weekly demos and wrote handover docs.

## Result
The project served 29k users in the first month.
