# REST API backend for insurance mobile app

**Client:** Forge Metals (insurance) · **Year:** 2021

## Problem
Forge Metals needed help with rest api backend for insurance mobile app. Their team had tried spreadsheets and ad-hoc scripts, and the process did not scale.

## What I did
I designed and built the solution end to end using server-side JS, RESTful endpoints, PostgreSQL, Express and Docker. I ran weekly demos and wrote handover docs.

## Result
The project raised conversion by 41%.
