# Django platform for logistics bookings

**Client:** Greenroots NGO (logistics) · **Year:** 2022

## Problem
Greenroots NGO needed help with django platform for logistics bookings. Their team had tried spreadsheets and ad-hoc scripts, and the process did not scale.

## What I did
I designed and built the solution end to end using batteries-included Python web framework, Postgres, Python, Redis and container images. I ran weekly demos and wrote handover docs.

## Result
The project served 8k users in the first month.
