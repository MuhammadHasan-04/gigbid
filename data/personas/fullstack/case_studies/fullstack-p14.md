# End-to-end test suite for a insurance web app

**Client:** Wayfarer Trips (insurance) · **Year:** 2026

## Problem
Wayfarer Trips needed help with end-to-end test suite for a insurance web app. Their team had tried spreadsheets and ad-hoc scripts, and the process did not scale.

## What I did
I designed and built the solution end to end using browser end-to-end tests, typed JavaScript, React and containerised services. I ran weekly demos and wrote handover docs.

## Result
The project brought latency down to 250 ms p95.
