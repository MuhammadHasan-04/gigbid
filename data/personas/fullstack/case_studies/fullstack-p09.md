# End-to-end test suite for a SaaS web app

**Client:** Harbor Supply (SaaS) · **Year:** 2023

## Problem
Harbor Supply needed help with end-to-end test suite for a saas web app. Their team had tried spreadsheets and ad-hoc scripts, and the process did not scale.

## What I did
I designed and built the solution end to end using Playwright, TypeScript, JS unit tests, container images and React. I ran weekly demos and wrote handover docs.

## Result
The project reduced cloud cost by 15%.
