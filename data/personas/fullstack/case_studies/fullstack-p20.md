# REST API backend for media mobile app

**Client:** Stackwise (media) · **Year:** 2024

## Problem
Stackwise needed help with rest api backend for media mobile app. Their team had tried spreadsheets and ad-hoc scripts, and the process did not scale.

## What I did
I designed and built the solution end to end using a JavaScript backend, RESTful endpoints, PostgreSQL, decorator-based Node services, Express and container images. I ran weekly demos and wrote handover docs.

## Result
The project brought latency down to 120 ms p95.
