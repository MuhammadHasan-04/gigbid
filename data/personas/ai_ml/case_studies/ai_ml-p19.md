# Multi-agent workflow for insurance operations

**Client:** Harbor Supply (insurance) · **Year:** 2023

## Problem
Harbor Supply needed help with multi-agent workflow for insurance operations. Their team had tried spreadsheets and ad-hoc scripts, and the process did not scale.

## What I did
I designed and built the solution end to end using python 3, multi-step agent workflows, GPT function calling, container images, FastAPI and asynchronous workers with a broker. I ran weekly demos and wrote handover docs.

## Result
The project brought latency down to 80 ms p95.
