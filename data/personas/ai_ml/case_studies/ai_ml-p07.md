# Document image classification for e-commerce

**Client:** Greenroots NGO (e-commerce) · **Year:** 2025

## Problem
Greenroots NGO needed help with document image classification for e-commerce. Their team had tried spreadsheets and ad-hoc scripts, and the process did not scale.

## What I did
I designed and built the solution end to end using Python, image understanding, torch and an async Python API. I ran weekly demos and wrote handover docs.

## Result
The project brought latency down to 80 ms p95.
