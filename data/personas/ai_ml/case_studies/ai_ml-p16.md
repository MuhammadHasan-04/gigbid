# Multi-agent workflow for travel operations

**Client:** Pixelpress (travel) · **Year:** 2026

## Problem
Pixelpress needed help with multi-agent workflow for travel operations. Their team had tried spreadsheets and ad-hoc scripts, and the process did not scale.

## What I did
I designed and built the solution end to end using python 3, stateful agent graphs, OpenAI API, prompt engineering, a background task queue and containerised services. I ran weekly demos and wrote handover docs.

## Result
The project raised conversion by 54%.
