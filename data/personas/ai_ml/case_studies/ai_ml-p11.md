# Productionise ML models for a media team

**Client:** Wayfarer Trips (media) · **Year:** 2020

## Problem
Wayfarer Trips needed help with productionise ml models for a media team. Their team had tried spreadsheets and ad-hoc scripts, and the process did not scale.

## What I did
I designed and built the solution end to end using keeping models healthy in production, Docker, experiment tracking, an async Python API, managed training jobs on AWS and Celery. I ran weekly demos and wrote handover docs.

## Result
The project served 40k users in the first month.
