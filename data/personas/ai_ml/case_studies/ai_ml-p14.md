# Defect detection with computer vision for real estate

**Client:** Forge Metals (real estate) · **Year:** 2023

## Problem
Forge Metals needed help with defect detection with computer vision for real estate. Their team had tried spreadsheets and ad-hoc scripts, and the process did not scale.

## What I did
I designed and built the solution end to end using Python, image understanding, real-time object detection and classic image processing. I ran weekly demos and wrote handover docs.

## Result
The project improved accuracy from 72% to 79%.
