# Multi-agent workflow for fintech operations

**Client:** Wayfarer Trips (fintech) · **Year:** 2024

## Problem
Wayfarer Trips needed help with multi-agent workflow for fintech operations. Their team had tried spreadsheets and ad-hoc scripts, and the process did not scale.

## What I did
I designed and built the solution end to end using Python, LangGraph, GPT function calling, careful system prompts, Docker and an async Python API. I ran weekly demos and wrote handover docs.

## Result
The project raised conversion by 35%.
